This project takes weather details from the website openweather every 3hrs. This website provides limited api key request (total 1,00,000 for free), and hence when
these requests are exausted, the project stops working, so if you want to make project work, just put new api key from the website and change latitude and longitude
of your position to get perfect data.
This project is a practice of AI prompting is is hence made by using codex using giving different prompts and instructions.
